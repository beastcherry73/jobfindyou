# 01_DESIGN_SYSTEM: Theme & Brand Style Guide

## Theme: Arctic Horizon
The visual language is characterized by deep oceanic dark colors, off-white cream surfaces, structured layout lines, and rich, high-contrast text.

### Color Palette (Tokens)
*   **Dark Navy**: `#08111F` (Used for dark section backdrops, primary text in cream layouts)
*   **Cream**: `#F8F5EF` (Used for alternative section backdrops, card bodies in light layouts)
*   **Primary Blue**: `#2563EB` (Brand indicators, main CTA fills, interactive hover triggers)
*   **Sky Accent**: `#7CC8FF` (Subtle shadows, borders on navy card layouts, hover underlines)
*   **Light Gray**: `#FAFBFC` (Light backgrounds, standard controls background)
*   **Border Gray**: `rgba(8, 17, 31, 0.08)` (Borders in light viewports)
*   **Border Sky**: `rgba(124, 200, 255, 0.15)` (Borders in dark viewports)

### Typography
*   **Headers (Display)**: `Manrope`, sans-serif. Used for `.l-title`, badge elements, and subheaders.
*   **Body & UI Controls**: `Inter`, sans-serif. Used for reading blocks, copy text, lists, and inputs.

### Spacing & Grid
*   Follow an 8px grid system for margins, padding, and alignments (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `80px`, `120px`).
*   Large section padding: `140px 24px` for generous, modern workspace breathing room.

### Borders & Shadows
*   **Card Border Radius**: Maximum `20px` (or `24px` for hero wrappers).
*   **Shadows**: Strictly below `25%` opacity. Always utilize large, diffuse blurs rather than hard offsets.
    *   *Light Drop Shadow*: `0 10px 30px rgba(0, 0, 0, 0.03)`
    *   *Deep Dark Shadow*: `0 25px 60px rgba(0, 0, 0, 0.35)`
