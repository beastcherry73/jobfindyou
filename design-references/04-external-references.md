# External References — with verdicts

Every outside inspiration reviewed this session, each with a clear keep/reject.
Borrow the *principle*, never the literal framework code. Adapt into `--js-*` tokens.

## Foundation
- **jobspike.in marketing page** — the north star. Preserve its identity;
  extend it inward. Real product UI (sample profile, ATS 61→93 before/after),
  not decorative imagery.

## Screenshots reviewed
- **Flux (health dashboard)** — REJECT the palette (neon lime + purple bubble
  charts = wellness-app signal, wrong for career-tech). KEEP the trick of
  promoting ONE metric card via colour inversion for hierarchy.
- **BizLink (CRM)** — KEEP the kanban pipeline + the selected-card-expands-to-detail
  pattern (no modal) + the compact KPI strip. REJECT the moody dark-agency mood.

## Sites reviewed
- **tsenta.com** (YC) — KEEP the "transparent agent" receipt with +/− diffs and
  staged workflow labels. Trust through visibility. (→ Improve receipt.)
- **lineaprompt.com** — KEEP the audit-trail + version-diff ("Time Machine") and
  the upfront trust/privacy note. (→ Builder versions, upload trust line.)
- **resumax.ai** — a SCOPE reference (features: scoring, rewrite, job matching,
  interview prep, cover letters), NOT a visual one. Warning: don't let its scope
  creep into JobSpike; each feature is its own product decision.
- **noth.in** — REJECT for the app. Creative-agency portfolio; bouncy scroll
  motion suits marketing/portfolio, not a working dashboard.
- **serotoninn.com** — REJECT the literal gothic-fashion look. KEEP the principle:
  constraint breeds personality (limit palette/type so every choice works harder).
- **madewithgsap.com** — Confirms the existing marketing funnel order is sound
  (progressive disclosure of value). No change needed there.
- **dock.cool** — Widget/multi-profile customization = a FUTURE personalization
  idea, not core now.
- **rocketweblabs.com** — Not relevant (real-estate agency site).

## Live browse sources (no MCP connector needed — just browse the web)
- **21st.dev** — component gallery (React/Tailwind). Use for layout/interaction
  patterns: sidebars, KPI cards, kanban, charts, empty states. Extract the
  pattern, REBUILD in vanilla CSS `--js-*`. Never paste its React/Tailwind code.
- **refero.design** — UI/UX inspiration library of real product screens. Use for
  layout, hierarchy, spacing, and interaction reference. If a screen there fits
  JobSpike's calm/premium family, adapt it — do not clone it or its brand.

## Excluded on purpose
- **Higgsfield** — a PAID AI video/image generator, NOT a layout reference, and it
  contradicts the "no decorative AI media" direction. Do not use.
