# Refero pick 5: Dub

**Source:** styles.refero.design · **Type:** clean analytics/SaaS reference
**Status:** KEEP — for lists, tables, and analytics readouts.

**Why it fits JobSpike:** Dub (link management) has an exceptionally clean analytics
dashboard — tables, filters, charts, and time-series presented without noise. Maps
to JobSpike's list-and-detail screens.

**Borrow:** understated line/area charts (fits our 20%-fill sparkline rule), tidy
sortable tables/rows, filter patterns, empty states, restrained use of one accent
on interactive elements.

**Avoid:** developer-tool coldness; keep JobSpike's warmer editorial tone.

**Applies to:** Previous Analyses list, Analysis report tabs, career-progress charts.
