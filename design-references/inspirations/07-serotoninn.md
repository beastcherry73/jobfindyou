# Inspiration: serotoninn.com

**Type:** live site (fashion brand)
**Status:** REJECT the look — KEEP one principle.

**What it is:** A gothic/club-culture fashion site — "glam meets grunge," bracket
typography, drag-scroll, high-contrast monochrome + metallic accents, provocative
imagery.

**Borrow:** the principle only — **constraint breeds personality**. A tightly
limited palette and type set makes every choice work harder and reads as
intentional/premium.

**Avoid:** the literal execution — brackets, drag-scroll, fashion imagery have no
place in a career product.
