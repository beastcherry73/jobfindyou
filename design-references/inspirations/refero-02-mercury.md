# Refero pick 2: Mercury

**Source:** styles.refero.design · **Type:** premium financial dashboard reference
**Status:** KEEP — for trustworthy, data-dense-but-calm metric screens.

**Why it fits JobSpike:** Mercury (business banking) makes numbers feel premium and
trustworthy without clutter — a hard, relevant problem, since JobSpike leads with a
Resume Health score and ATS/recruiter metrics. It shows how to present money-grade
data calmly.

**Borrow:** how it frames a hero metric with supporting context (→ our score-as-
instrument), generous spacing around numbers, quiet tables, trust through
understatement, tabular figures.

**Avoid:** fintech-specific chrome; keep JobSpike warmer and more human.

**Applies to:** Dashboard resume-health instrument, Analysis report, any metrics.
