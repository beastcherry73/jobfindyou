# Refero pick 1: Linear

**Source:** styles.refero.design (publicly catalogued) · **Type:** product-craft reference
**Status:** KEEP — the gold standard for JobSpike's app shell & dashboard.

**Why it fits JobSpike:** Linear is the benchmark for calm, restrained, high-craft
product UI — precise spacing, quiet neutral surfaces, one accent used sparingly,
keyboard-first, mostly still (motion only where it aids understanding). This is
exactly the "premium, professional, not AI-slop" bar we've set.

**Borrow:** information hierarchy, the restraint (accent ~5% of pixels), sidebar +
content shell, the discipline of near-zero decoration.

**Avoid:** Linear's cool grey/indigo palette — keep JobSpike's warm ivory + cobalt.
Borrow the *discipline*, not the colours.

**Applies to:** overall app shell, Dashboard, every authenticated screen.
