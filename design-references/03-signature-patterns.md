# JobSpike Signature Patterns

Distinctive components designed for JobSpike this session. Reuse and refine these
rather than reinventing generic cards/bars/rings. Each answers a specific question.

## 1. Score as a diagnostic instrument
Not a bare ring. A ring (current health) + a causal factor breakdown
(ATS +18, Keywords +12, Experience +7, Structure +4) + a trend sparkline
("+14 since last optimization"). Answers "what's my score AND what's driving it"
in one footprint.

## 2. Receipt-style before/after (Improve)
Itemized diff with explicit +/− marks and a reason per line, plus the score jump
(ATS 84 → 91). Borrowed from transparent-agent products (Tsenta) — showing the
AI's reasoning builds trust for anxious users. Beats a plain two-paragraph diff.

## 3. Resume-composition donut = navigator
An interactive donut of resume sections (Experience 52%, Skills 21%…). Clicking a
segment scrolls the resume preview to that section. A chart that DOES something,
not decoration.

## 4. Stage spine (Applications) — the signature
A 4-node momentum rail on every application card (Saved → Applied → Interview →
Offer), filled to the current stage, so you read momentum across the whole board
at a glance. A selected card expands IN PLACE (no modal) into a vertical event
timeline (applied date, recruiter viewed, next suggested action).

## 5. NOW / NEXT / MOVING dashboard narrative
Three labelled layers instead of a grid of equal stats:
- NOW — resume health (the instrument).
- NEXT — the single highest-impact coach recommendation + one action.
- MOVING — recent analyses, applications, career progress.

## 6. Card-expand-to-detail
Selected item expands inline to show detail, rather than opening a modal. Keeps
context. (From the BizLink CRM reference.)

## 7. Version diff (Builder)
The Versions tab shows a visual diff between two resume versions (old struck /
new highlighted), not just a list of dates. (Time-Machine pattern from Linea.)

## 8. Improve = three choices, not twelve tools
"Improve entire resume" · "Improve a section" · "Compare before & after."
All the AI mechanics (ATS, keywords, grammar, verbs, metrics) run underneath.

## 9. Appearance selector
A Light / Dark / System segmented control (sun / auto / moon) in the app top bar,
with a sliding thumb. Dark mode is re-mapped, not inverted.

## Icons
Use a consistent stroke SVG line-icon set (Lucide/Heroicons style) — NEVER emoji.
